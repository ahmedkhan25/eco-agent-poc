# About-modal explainer diagrams

Drop one PNG per section here, named to match its `imageSrc` in
`src/lib/demo/about-content.ts`:

```
overview.png            king-tide.png          septic-priority.png
risk-report.png         grant-finder.png       adaptation-pathways.png
hurricane-playbook.png  a1a-coastal.png        tree-canopy.png
stormwater.png          code-assistant.png     tourism-loop.png
triage.png              equity.png             ghg.png
```

Recommended export: 1280×720 (16:9) PNG.

Until a PNG exists, the About modal shows a styled placeholder plus the
image-generation prompt (also collected in
`/EcoHeart_About_Modals_Content.md`). Each prompt already carries the shared
EcoHeart visual style (dark navy-teal, heart-network motif, deck footer ribbon)
so the 15 diagrams render as one family.
